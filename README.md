# PerfDSL
A contract specifier that helps authors build Domain Specific Langauges with ease and rapid progression.

Tvastr lets researchers build new high-performance GPU DSLs without repeatedly hand-writing layout reasoning, verifier logic, rewrite guards, schedule-space plumbing, testing scaffolds, and MLIR backend glue. Or atleast that's the future intention.

Currently the project is in it's infancy. Verifying whether the contract system provides valid correct code before we progress to c++/MLIR
